# Requirements registry

This folder holds the product law for tn5250-cli. One row is one requirement file. Active means the file is in force.

Windows Git Bash CLI coding is `requirement-windows-git-bash-cli-coding.md`. The Windows Git Bash payload build is `requirement-windows-git-bash-build-payload.md`. Debian CLI coding is `requirement-debian-cli-coding.md`. The Debian payload build is `requirement-debian-build-payload.md`. Ubuntu compilation, link, and build are `requirement-ubuntu.md`. Other Linux compilation, link, and build are `requirement-other-linux.md`. Alpine CLI coding is `requirement-alpine-cli-coding.md`. The Alpine payload build is `requirement-alpine-build-payload.md`. Termux CLI coding is `requirement-termux-cli-coding.md`. The Termux payload build is `requirement-termux-build-payload.md`. macOS CLI coding is `requirement-macos-cli-coding.md`. The macOS payload build is `requirement-macos-build-payload.md`. Fedora and Red Hat Enterprise Linux CLI coding is `requirement-fedora-redhat-cli-coding.md`. The Fedora and Red Hat Enterprise Linux payload build is `requirement-fedora-redhat-build-payload.md`. `requirement-domain-tn5250.md` is the domain law for build and host launch. `requirement-payload-filename.md` owns the published payload filename in `download/` and the `setup` download. `requirement-shell-cli-language.md` owns the English language board. `requirement-shell-sudo-command.md` owns the one sudo wrap that installs missing compiler packages on Debian, Ubuntu, other Linux, Alpine, Fedora, and Red Hat Enterprise Linux. Debian's `apt` names for Debian 12 and 13 stay on the Debian payload requirement. Alpine's `apk` names stay on the Alpine payload requirement. macOS Homebrew formula names stay on the macOS payload requirement. The `dnf` names stay on the Fedora and Red Hat payload requirement. Termux, macOS, and Git Bash do not use that wrap. The build verb is the mixed elevated sudo model: one command for a normal user and for a sudo launch. Git and the compile stay with that person. Wrapping the whole command in sudo is not the design. The Type 0 rows own the CLI binary’s lifecycle, output, storage, and re-run rules. The other rows point. They do not restate a platform build.
